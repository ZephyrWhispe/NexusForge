# 07 系统管理面板详细设计（B1 接线 + 深化）

> 总纲：docs/impl/09 §7；对标：NeoHtop（蓝本 §3.12）+ UniGetUI（§3.8）+ WinUtil + TreeSize/Autoruns；状态：未开工。

## 1. 现状问题

- 四 Tabs（监控/清理/包管理/调整）已有，但**蓝本 §3.12"进程管理：列表、排序、搜索、结束进程"整块缺失**（metrics.rs 只有 PDH 采样环，无进程枚举）。
- 孤儿命令：`sys_clean_targets`（清理目标管理）、`winops_catalog`（43 项目录）——scan 结果之外无浏览面，用户看不见"能调什么"。
- 包管理动作集只有 install/uninstall/upgrade_all（`pkg.rs:213/315/391`）：**无仓库搜索、无单包升级、无源管理**——UniGetUI 主卖点全缺。
- `needs_admin` 项只显示状态，无"提权重试"动作；托盘无 CPU/内存负载显示（§3.12 明确要求，D-26 set_title 通路已在）。
- 监控无磁盘 IO/GPU/温度，历史 300 点不持久化不导出；无阈值告警。
- 无开机启动项视图（Autoruns 心智完全空缺）。

## 4. 其他软件借鉴

- **WinUtil**：Tweaks 的"默认/推荐/自定义"三档按钮组与执行日志流——diff 预览 + 套餐预设照此形态；
- **NeoHtop**：进程树折叠 + 右键杀进程子树（"结束进程及子进程"）；
- **UniGetUI**：安装来源角标（winget/scoop/choco）+ 已装/可升级双色徽章；
- **Task Manager 详细信息页**：列自选 + 置顶小字状态——进程页列配置。

## 5. 拓展设计（常人未思）

1. **进程保护名单硬编码红线**：csrss/lsass/wininit/services/svchost(系统账户组) 拒绝结束（本地名单+以会话归属判定），负例测试——把"误杀"关进笼子才有资格给"结束进程"。
2. **磁盘告警→automation 事件**：空间低于阈值 publish `sys.disk_low`，用户可挂规则（自动清理/仅通知）——跨模块闭环，蓝本没有、WinUtil 没有。
3. **注册表 diff 预览**：apply 前展示每动作 旧值→新值 表（备份读回比对），verify 失败自动回滚已有（BAVR），把"敢不敢点"变成"看得懂再点"。
4. **一键还原全部本工具所做调整**：BackupStore 按 origin 聚合 → "撤销 NexusForge 的全部改动"（信任设计）。
5. **"我的电脑健康周报"**：本地聚合卡（可清理量/可升级数/调整漂移/磁盘趋势），只读数据全部本地，可一键转发 automation 通知。

## 6. 验收点

- 进程页：排序/搜索/结束（含保护名单负例）；treemap 扫描可取消；
- `sys_pkg_search` 结果卡→安装 cmd_preview 一致；单包升级路径；
- catalog 浏览 43 项全覆盖 + diff 预览 + needs_admin 重试走 helper；
- 托盘负载开关生效且 CPU 采样失败时静默降级（负例）；
- 全部新命令 permissions+capability 同步；启动项 HKLM 写路径必须经提权 helper（红线负例：capability 断言 webview 无任意注册表写命令）。

## 7. 排版方案与二审补充（2026-09-19 复审）

### 7.1 排版方案（逐子面板）

- **概览**：四指标卡网格（CPU/内存/磁盘/网络，卡片内曲线+当前值大字），卡下 Top4 进程 mini 表与告警流双列；磁盘卡**永不静默**——剩余低于阈值时红描边（本战役 C 盘 10054 满盘事故的 UI 化）。托盘负载开关放 PanelHeader 右侧。
- **进程**：DataToolbar `[搜索XL][刷新][列设置]`；表行 `[PID][名称+账户][CPU%右靠定宽][内存][磁盘IO][网络]`，排序头点击切换（00§5）；右键菜单与行悬停"…"一致：结束进程/结束进程树/打开文件位置/复制；"结束进程"在 destructive 分隔线下且二次确认显示进程名（防误杀，§5-① 保护名单命中时直接禁用+tooltip 原因）。
- **启动与恢复**：三折叠节（启动项/服务/计划任务），行布局统一 `[名称+发布者][源角标：Run夹/注册表/任务][状态Badge][Switch]`；HKLM 项的 Switch 置灰并 tooltip"需管理员，点击经由提权重试"（00§4-④ 禁用必附原因）。
- **存储与清理**：clean_targets 管理表在左、treemap 画布在右（可全屏切换）；treemap 扫描中显示进度与取消钮，颜色图例固定角落；"执行清理"为 destructive 流（预览清单→确认，cmd_preview 纪律同源）。
- **软件**：已装表行 `[名称+版本][源角标 winget/scoop/choco][状态：可升级↑x/最新/未知][操作…]`；在线搜索为同页切换态（搜索框 XL + 结果卡列表，"安装"进 cmd_preview）；可升级徽标计数在 SubNav 项上；源管理卡列表带"修复指引"展开行。
- **系统调整**：左侧分类树（43 项按 catalog 分组）+ 右侧该项卡片：`[当前状态][拟改为][风险级别Badge][needs_admin角标]`；**diff 预览表**（旧值→新值）在"应用"按钮上方就地展开，不弹独立对话框；预设套餐为顶部芯片组（默认/推荐/自定义）；"全部还原本工具改动"放页 Footer destructive 区。
- **设置**：分组序=采样与告警（阈值数字字段定宽160+单位）→托盘显示→历史持久化；磁盘告警阈值默认值与概览红描边联动。

> **D-43 实施状态（2026-09-30，C6 落地＋真机实测）**：概览/清理/包管理/系统调整四枚互斥视图由页内 `<Tabs>` **上移到左轨**（视图键 `sysTab`，切走再回不丢），每视图恰一枚吸顶 `DataToolbar`（实测高 40、`position:sticky`、`top:0`），首层区块全部立标题，三枚内层 `maxHeight` 视口收敛为主体单滚动＋`ListFooter`"显示更多"分页，**三处静默截断全部开口**（实测上屏原话＝"进程 60 行 · 采样 300 / 300 点"）。真机实测：资源监控档滚动面 max **2478**（1280）／**2604**（940），`scrollTop` 达 max 且末块底 699.6／700 入视界、无横向溢出；包管理视图的页脚按清单在场态出现（实测该视图 0 枚＝当前无已装列表数据）。**行为变更如实登记**：`<Tabs>` 上移改变键盘焦点次序与计数徽标位置，`cleanTargetsCatalog`／`sysPanelPkgSearch` 一类逐字文本夹具是改锚而非放松。未做＝四指标卡网格与磁盘红描边、Top4 mini 表＋告警流双列、启动项/服务/计划任务三折叠、treemap 画布与源管理、`cmd_preview` 预览确认流、SubNav 可升级徽标计数——除网格排版外均需新 Rust 命令，归后续批。

### 7.2 配套功能缺口（二审新增）

1. **卸载残留扫描**：包管理只列"已装"，用户真正喊的是"卸了还有残留"。配套只读清单（注册表 Run 孤儿项/安装目录遗骸/开始菜单死链）→ 逐项确认后删（进回收站/备份后写），与进程保护名单同纪律：**只列不改、改必确认**，负例测试覆盖"运行中程序目录不得出现在删除清单"。
2. **进程优先级/亲和（可选低优先）**：NeoHtop 没有但 Task Manager 有——右键增设"设优先级/相关性"，needs_admin 联动提权 helper；明确不做服务/悬挂进程等进阶视图（登记边界）。
3. **计划任务"下次执行"列**：启动与恢复页计划任务节补 下次执行时间/上次结果码 两列——排障信息，枚举即有，缺渲染。
4. **告警预设模板**：阈值告警（CPU 持续高/磁盘将满/内存压力）不自造引擎——落为 automation 预置规则模板（`sys.disk_low`/`sys.metric_alert` 事件 + 通知动作），用户一键启用，与 §5-② 同源；设置页只暴露阈值与开关，规则本体归 13-automation，避免两处编辑。
5. **服务操作边界**：本期启动项节对"服务"只读枚举 + 启动类型展示；启停服务需提权且风险高，登记为 B8 议题（不做半吊子禁用按钮）。

### 7.3 锦上添花

1. **"刚才卡了"快照**：CPU/内存连续 N 秒超阈值时自动留存当刻 Top 进程快照到历史流，概览告警卡可回看——事后取证是系统管理最缺的时间维度。
2. **清理前磁盘对比**：清理执行卡片显示 前→后 可用空间 diff（两次采样的已有数据），把"清了什么"变成看得见的一行字。
3. **调整项"漂移检测"**：catalog 项应用后定期回读值，被外部（组策略/更新）改回时告警流提示"已偏离"——§5-④ 健康周报的子信号。

### 8.3 边界与红线（登记，不做半吊子）

- **粉碎/擦除空闲空间**：SSD 语义弱且不可恢复——v1 不做，工具箱挂 DeferredBadge；
- **Wi-Fi 密钥/产品密钥导出**：凭据级敏感——若做必须解锁 vault 前置+一次性展示+永不入导出文件（负例：导出包全文不含密钥）；默认不列入 v1；
- **VirusTotal 查询（Autoruns 式）**：外发哈希=隐私边界——不做默认行为，automation 可自组（登记）；
- **CleanerML 式声明式规则库**：架构方向登记（清理目标从硬编码白名单演进为可校验 schema 的规则文件），**白名单不可扩任意路径红线不动**——schema 校验拒绝对外通配（负例测试）；
- 全部策略键写入沿用 winops catalog id 前缀规范+BackupStore BAVR；新增枚举/扫描/管控命令一律 permissions+capability 同步，`update_*`/`uninstall_*` 只进 main capability（D-28 aux-window ban 表扩充）。

### 8.4 排版与验收增量

- 更新管控页：档位卡在上（三选大卡互斥 Radio 卡形态）、细调 SwitchSetting 组居中、危险区居底黄边容器（ExpertGate 关闭时整容器不渲染，非灰态——防"看得见够不着"）；"当前生效状态"回读横幅常驻页头（Get Installed Tweaks 思想：显示系统实态而非本工具最后意图）；
- 卸载工作台：多选替换式操作条（04-file 同语言）；残留结果表分组节头带计数芯片；
