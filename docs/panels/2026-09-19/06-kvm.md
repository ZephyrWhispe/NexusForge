# 06 键鼠共享面板详细设计（B1 接线 + 深化）

> 总纲：docs/impl/09 §7；对标：Lan Mouse（蓝本 §3.7）+ Deskflow/Barrier/Input Director；状态：未开工。

## 1. 现状问题

- `kvm_session_list` 拉而不渲（只用于"会话中"判定）——活跃会话/流量/对端零可见。
- `kvm_send_clip`、`kvm_send_file` 孤儿：跨机推送无 UI（D-24 只做了接收回写方向）。
- 边缘只有 left/right：蓝本多屏任意方位；上/下缘缺失。
- 输入投影面缺：水平滚轮、XButton1/2（win-integration 勘查"透传不捕获"）；修饰键状态不同步（切机时 CapsLock 灯态漂移——Lan Mouse 已处理的老坑）。
- 无分享策略控制（剪贴板类型开关、文件大小上限硬编码）。
- 发现/配对流程说明是纯文字，新手无从下手。

## 2. 子面板信息架构

| 子面板 | 类型 | 内容 |
|--------|------|------|
| 概览 | 概览 | 本机身份（设备名/指纹）+ 控制状态大字 + **边缘拓扑图**（见 §5-①）+ 一键切回 + 当前会话速率 |
| 设备 | 清单 | 发现的设备（mDNS 实时流）+ 已配对（卡片区：名称/角色/共享边缘 Select 四向/延迟/最后在线 + 连接/解除）+ 配对码大按钮（发码/输码双列）|
| 会话 | 清单 | 活跃会话表（对端/方向/建立时间/字节数/RTT）+ 断开 + 历史会话（新落盘表）|
| 共享 | 设置+清单 | 剪贴板共享开关与类型（文本/图片/文件）+ 文件保存目录与大小上限 + **共享历史**（推送/接收流水，可撤回剪贴板项）|
| 诊断 | 概览 | 端口 49800/49801 占用自检 + 防火墙规则提示（检测不自动改，红线）+ 同网段可见性测试 + 指纹比对提示（两侧人工核对流程引导）|
| 设置 | 设置 | 边缘切换热键（释放键 Ctrl+Alt+Shift+Q 展示/改）、冷却 100ms 可调、防误触容差、设备分组（家庭/办公 profile）|

## 4. 其他软件借鉴

- **Deskflow 的"无盘接管"提示**：被控端屏幕角落常驻小指示（谁在控制我）——安全透明性，PinWindow 通路可画角落浮标；
- **Input Director 的宏动作**（切换时触发锁屏/静音）→ 落 automation 事件（`kvm.edge_switched` 总线事件，规则可订阅）而非自造宏引擎；
- **Lan Mouse 的极简配对**：一键"等待对端"全屏态——配对流程的焦虑设计；
- **Barrier 屏幕布局**：拖矩形排布多屏（§5-①）。

## 5. 拓展设计（常人未思）

1. **边缘拓扑图**：俯视画布上把本机与对端画成方块，拖动摆位自动生成共享边缘映射——把"抽象 Select 选项"变成"物理直觉"，Barrier 用户公认的价值时刻。
2. **文件推送断点面板**：4MB chunk 通道已有，UI 显示每文件进度条 + 暂停/续传（bitmap 已有，缺暴露）。
3. **跨机粘贴历史**：对端来的 ClipData 入剪切板模块（已做 origin=remote）之外，KVM 子面板留"最近跨机项"快捷再推（回推方向）。
4. **配对指纹变更告警**：paired.json 指纹变化 → 强制重配对 + 红色横幅（中间人/重装取证），负例测试。
5. **"我只借走半块屏"**：边缘共享时段控制（如仅工作时间启用右缘）——office 隐私场景，Director 无、Deskflow 无。

## 6. 验收点

- 会话表实渲（含断开按钮生效）；send_clip/send_file 双向冒烟；
- 四向边缘 + 拓扑图 → edge_map 落盘一致（含上缘/下缘新值域回归）；
- XButton/水平滚轮注入单测（RawInput 投影函数级）；
- 指纹变更负例；诊断页各检查独立可失败（谓词自检）。

## 7. 排版方案与二审补充（2026-09-19 复审）

### 7.1 排版方案（逐子面板）

- **概览**：上半区左右两卡——左"本机身份"（设备名/指纹等宽字体+复制钮），右"控制状态"大字（控制中/被控中/空闲 + 当前边缘）；下半区**边缘拓扑图**为唯一主角，占满宽度、高度固定 260px，禁止与文字说明混排。"一键切回"主按钮在状态卡右下。
- **设备**：已配对卡片网格（每卡 `[名称][角色Badge][共享边缘 Select 四向][延迟][最后在线][连接/管理…]`）；发现中设备为流式列表置顶区，带"配对"次按钮；配对码页双栏 `[我这边生成][对方输入]`，按钮"等待对端"全屏态（§4 Lan Mouse 借鉴的落地位置）。
- **会话**：清单标准表（00§5），行 `[对端][方向箭头][建立时间][字节数][RTT，色阶][断开]`；断开为 destructive（分隔线下）；历史会话为同页第二折叠节。
- **共享**：上半 SwitchSetting 组（文本/图片/文件三开关，级联：总开关关则子项置灰并 tooltip 说明，00§4-④），下半共享历史流水表；文件目录用 PathPicker（00§3），大小上限数字字段定宽 160+后缀"MB"。
- **诊断**：检查项卡片列表，每项 `[状态图标][检查名][详情副行][重测钮]`，各检查独立可失败（§6），全绿时 EmptyState 文案"全部通过"而非空白。
- **设置**：分组序=边缘与热键（前置依赖）→防误触参数→profile 分组；热键展示为只读快捷键胶囊+"修改"按钮，禁手打键位串。

### 7.2 配套功能缺口（二审新增）

1. **临时暂停 / 游戏排他**：KVM 最经典的客诉源——全局钩子在全屏独占应用（游戏/演示）里造成卡顿或误触。配套：总开关（托盘菜单项+概览大字卡按钮，同一 `kvm.enabled` 状态）+ **前台全屏独占窗口检测自动挂起**（检出即释放钩子、退出即恢复，状态行可看到"因全屏应用暂时挂起"）。不做则"键鼠共享"变成"要不要玩前先退软件"。
2. **锁屏/会话切换联动释放**：本机锁屏或 Win+L 时立即停止注入与被控通道（安全配套，与 03-vault 锁屏触发同事件源）；负例测试：锁屏事件后注入计数为 0。
3. **分辨率/DPI/显示器变更重匹配**：边缘映射按虚拟屏幕坐标算好，显示拓扑一变（插拔显示器/改分辨率）若不重算，鼠标会"穿越到墙里"。配套：监听 WM_DISPLAYCHANGE 重建 edge_map，并在设备页顶部横幅提示"屏幕布局已变化，请核对边缘"。
4. **角落指示开关入设置**：§4 Deskflow"谁在控制我"浮标从借鉴升为配套——被控端设置里有"显示控制指示器"SwitchSetting（默认开；关掉它等于关掉安全透明性，文案须警示）。
5. **防火墙预检与引导**：发现/连接失败的最常见根因（06 诊断页已有检测），配套升级为首次配对时的**前置体检**：检测 49800/49801 入站规则，缺失时给出"复制放行命令"（不自动改规则，红线维持）。

### 7.3 锦上添花

1. **"谁在动我的鼠标"审计行**：会话历史表加"方向+持续时长"统计卡，被控方心态安全感设计（数据即现有会话表聚合）。
2. **边缘穿越音效/震动反馈（可选）**：切机瞬间极短提示音，默认关——跨机操作最容易丢神的一刻给一点感官锚。
3. **设备分组 profile 快切**：概览页一个"当前方案"下拉（家/办公），切换即换边缘映射与共享策略，出差场景一步到位。
