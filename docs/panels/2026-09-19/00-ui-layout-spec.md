# 00 UI 布局与控件规范总纲（全应用共用 · 2026-09-19 二审增设）

> 地位：所有面板档 §7「排版方案」的共用底座；各档 §7 只写"本模块特有"的骨架与摆位，通用纪律一律引用本文不重复。随 B0 组件族落地（DeferredBadge/DataToolbar/EmptyState 同批），先于任何面板重构。
> 目标（用户裁定原话）："功能和逻辑都要通畅，按钮输入之类的元素摆放规整，减少相关问题。"——本文把这句话翻译成可检查的规则。

## 1. 页面骨架（模块工作区唯一形态）

```
┌ SubNav 190px ┬──────────────── 内容区（min-width 0，弹性）────────────────┐
│ 模块名       │ PanelHeader 48px：标题(左) │ 上下文摘要 │ 主操作区(右)      │
│ ○ 概览       ├──────────────────────────────────────────────────────────┤
│ ● 清单       │ DataToolbar 40px（清单类）：搜索·过滤(左) │ 批量操作(右)   │
│ ○ 编辑       ├──────────────────────────────────────────────────────────┤
│ ○ 历史       │ 主体：表/卡/表单（唯一允许纵向滚动的区域）                  │
│ ○ 设置       ├──────────────────────────────────────────────────────────┤
│  …           │ Footer 32px（可选）：选中 n 项·共大小·分页                  │
└──────────────┴──────────────────────────────────────────────────────────┘
```

- PanelHeader 固定不滚动；工具条随主体滚动吸顶；**页内永远只有主体一个滚动容器**（禁双层滚动）。
- 概览/设置类无 DataToolbar/Footer，骨架其余相同；编辑类（标注器/规则编辑器）主体可为"左列表右详情"二段，仍禁再嵌套分栏超过一层。

## 2. 间距与栅格（Fluent tokens 白名单）

- 间距只允许 `color/spacing` 系列中的 **4 / 8 / 12 / 16 / 24**；同层元素间距必相同（卡片墙禁"有的 12 有的 14"）。
- 卡片内边距 16；卡片间距 16；表单分组间 24 + Divider + 组标题；分组内字段间 12。
- 内容区左右留白 20（现各面板 Root padding 对齐之，禁各写各的）。
- 表列宽：文本列弹性（min 120），数字/日期/状态列固定（延迟 `--` 占位防抖宽）；长文本 ellipsis + title tooltip，**永不折行撑高行**（例外：详情抽屉）。

## 3. 控件规范（宽度档位与选型表）

| 场景 | 控件 | 档位 | 纪律 |
|------|------|------|------|
| 单行输入 | Input | S=120（数字/端口）/ M=240（名称）/ L=360（路径/URL）/ XL=fill（搜索） | 数字类禁 XL（输入框宽度=内容量级，防"超宽空框"）|
| 枚举 ≤5 项 | RadioGroup / Tab（互斥视图用 Tab） | — | 禁 Dropdown 装 3 个选项 |
| 枚举 >5 项 | Dropdown（选）/ Combobox（可输） | M/L | 选项含计数时用 "名称（N）" |
| 开关 | Switch + 标签 + 说明行 | 全宽行 | 见 §6 SwitchSetting |
| 数值阈值 | NumberField（步进）/ Slider（连续） | 固定 160 含后缀单位 | 单位写进 suffix，禁"（分钟）"悬在框外 |
| 路径选择 | PathPicker（Input+浏览按钮） | L | 禁逼用户手打绝对路径（本仓现病：editor PDF 三框）|
| 操作按钮 | Button | 高 32；图标按钮 24/28 | 文字按钮 ≤6 字，超出即文案缺陷 |
| 破坏性 | outline + `danger` | — | 永不与主操作相邻同组（中间必有 Divider 或换区）|

- 同一工具条按钮组右对齐时主操作**恒最右**；对话框按钮恒右下：`[取消] [保存/确认]`，全应用无镜像。
- 行内操作 ≤3 个直出 + "…"溢出菜单；超过 3 个全进溢出菜单（行 hover 才显操作钮，静态占位宽防抖）。
- 一切图标按钮必带 tooltip（含无障碍名）。

## 4. 逻辑通畅四律（"点了要有下文"）

1. **反馈三件套**：每个写操作必落其一——toast（轻）、行内状态变化（列表类）、跳转结果位（长任务→传输/历史页）；零反馈=缺陷，验收按此判。
2. **禁用必解释**：disabled 控件必附 tooltip 说明原因与解锁路径（"内核未运行，先到总览启动"），禁裸禁用。
3. **表单校验时序**：字段级 inline 错误（字段下方 `aria-describedby`），提交时滚动并聚焦第一错误；异步查重（重名/端口占用）在 blur 触发而非 submit 才报。
4. **加载与空态诚实**：主体区加载用与真实布局等高的 skeleton（防 CLT 跳动，D-18 基线延伸）；EmptyState 必含"为什么空 + 第一步动作"（空搜索≠空库两文案）；错误态含 重试/查看日志（D-18）。

## 5. 清单类统一（DataToolbar 细化）

- 左区：搜索（XL→M 自适应）→ 过滤芯片（可移除、显示计数）→ 排序 Dropdown；右区：批量操作钮组（选中>0 才亮，附"已选 n"）→ 新建主按钮（最右、primary）。
- 分页与虚拟滚动二选一：>200 行必虚拟滚动（剪切板 U4 行高修正教训：行高常量单一来源）；筛选态必显示"n / 共 m"。
- 行选中模型统一：单击=选中/展开详情（详情抽屉/内联，按各档定），双击=主语义（粘贴/打开），Ctrl 多选，禁"单击就触发不可逆"。

## 6. 设置页规范（每模块"设置"子面板共用组件族）

- 每行=SwitchSetting：`[标题(粗) + 说明行(灰,可含变量)] —— spacer —— [控件右端定宽]`；同页所有行控件右缘对齐同一基线（摆整的核心：**末端对齐**）。
- 分组顺序=**前置依赖在前**（先"启用 X"开关组，后 X 的参数组；参数组在 X 关时折叠而非禁用整段）。
- 每分组右上角"恢复默认"（ConfirmDialog）；每设置项悬停 tooltip 含当前值与"生效方式"（即时/需重启内核/需重开窗口）。
- **设置归位纪律**（README §0.2）执行细则：功能区原地曾有的设置迁走后，原位置留 gear 图标"打开相关设置"直达对应子面板锚点（防"我的按钮去哪了"）。
- schema 单源：宿主设置中心与模块设置子面板读同一 schema（B0 修复 moduleId 后成立），字段 id 即锚点 id。

## 7. 锦上添花（设置体验层，随 B0/B1 逐步交付）

1. **设置搜索**：设置中心顶部一框搜全模块 schema 字段（标题+说明+路径分词），结果行=面包屑式"模块 › 分组 › 字段"点击直达锚点。
2. **最近更改**：宿主记录"我改过什么设置"时间线（含旧值→新值、一键回退）——设置多了之后的导航刚需。
3. **配置包导出/导入**：全应用设置 zip（schema 值+模板+片段+规则），**红线负例**：不含凭据/私钥路径明文/updater 相关；导入走 diff 预览再确认。
4. **首次使用导览**：全新配置首启时按模块给 3 步内引导（截图热键/代理导入订阅/密码库解锁），可整体跳过且不再出现；解决"面板很多不知从何用起"。
5. **诊断快照**：设置中心底部"复制诊断信息"（版本/模块状态/端口占用，脱敏）——报障不再截图打字。

## 8. 可判定化（本规范的回归形态）

- 组件级 vitest：SwitchSetting 行控件右缘基线、按钮顺序（对话框主操作恒最右）、disabled 必带 title 的组件测试各一条（含负例样本）；
- eslint/stylelint 侧：spacing token 白名单（出现非 §2 数值即 warning→error 渐进）；
- 每面板档 §6 验收点引用本文条款号，实启冒烟加一条"骨架走查"：任一面板滚动容器 ≤1、工具条左右区摆放与 §5 一致。

## 9. 三审增补（UI 案例调研吸收，2026-09-19，来源见 90-research-system-ui.md §2）

1. **字号阶梯表（Win11 type ramp）**：Caption 12/16（表头、辅助说明）、Body 14/20（正文缺省）、BodyStrong 14/20 Semibold（分组标题）、Subtitle 20/28（PanelHeader 标题）、Title 28/36（概览大数字）；**正文最小 14px、任何文字最小 12px；标题用 Semibold 禁 Bold**；设置/说明类长文行长 45–75 字符（超宽窗体由 §9-② 列宽上限保证）。
2. **设置页与详情抽屉列宽上限**：纯文字设置流单列，**内容最大宽 1040px 居中**（Fluent app settings 1000–1100 取中），16:9 宽窗上信息不"摊大饼"。
3. **行高三档定值**：紧凑表格行 **48**、单行列表（图标16）44、双行列表（图标/头像 32–48）64；表头 Caption 12px+浅底+padding 12——补强 §5"行高单一来源"的具体数值。
4. **每分组可见项 ≤5**：低频项折叠进 SettingsExpander 式行卡（父行=标题+摘要，展开=子选项），**嵌套恒 ≤1 层**；关断的参数组用折叠（§6 既有条款的组件名定档）。
5. **设置搜索交互**：Ctrl+F 呼出 §7-① 设置搜索（宿主级快捷键），输入即出建议 flyout；**结果 >5 条进"全部结果"整页**（PowerToys 0.94 同款），结果行含"模块 › 分组 › 字段"面包屑。
6. **项级恢复默认**：每设置项 `…` 溢出菜单含"恢复默认（当前值→默认值）"，与 §6 组级恢复默认并存两级（VS Code 心智）；默认值来自 schema 单源，禁前端另表。
7. **banner 语义分工**：内联横幅**只承载状态告警**（内核未运行/磁盘将满/漂移提醒）；破坏性动作确认恒走 ConfirmDialog（D-18）——两条通道不混用，防"横幅疲劳"。
8. **双栏断点**：清单+详情二段布局在内容区 <640px 时降级为"列表/详情二选一+返回"（Fluent list-details 官方断点），≥640 并排；详情面板选中即更新，禁"点行再点打开"两步。
9. **即时生效与保存制式**：设置类修改**即时生效，页面无"应用/确定"钮**（Fluent/WT 一致）；表单类（新建实体/编辑条目）保留 `[取消][保存]`（§3）——两制式不混：同屏禁出现"设置行 + 底部应用钮"组合。
10. **About 区制式**：宿主"关于与更新"置底一行（图标+名称+版本），展开含诊断快照/依赖/法律链接（§7-⑤ 同位置合并）。
11. **二值控件选型备注**：维持 Switch（Fluent 官方立场）；Windows Terminal 新版改 CheckBox 一事记为**已评估不采纳**（防后续贡献者再度翻烙饼）。
12. **accent 用度**：强调色只标"当前选中/可交互/状态高亮"三类，正文对比 ≥4.5:1（WCAG/Fluent a11y）；浅深主题均用 Fluent 自动生成的对比版本，禁手调色值入 token。
