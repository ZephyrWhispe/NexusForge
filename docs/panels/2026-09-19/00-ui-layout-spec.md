# 00 UI 布局与控件规范总纲（全应用共用 · 2026-09-19 二审增设）

> 地位：所有面板档 §7「排版方案」的共用底座；各档 §7 只写"本模块特有"的骨架与摆位，通用纪律一律引用本文不重复。随 B0 组件族落地（DeferredBadge/DataToolbar/EmptyState 同批），先于任何面板重构。
> 目标（用户裁定原话）："功能和逻辑都要通畅，按钮输入之类的元素摆放规整，减少相关问题。"——本文把这句话翻译成可检查的规则。

## 1. 页面骨架（模块工作区唯一形态）

```
┌ SubNav 190px ┬──────────────── 内容区（min-width 0，弹性）────────────────┐
│ 模块名       │ PanelHeader 48px：标题(左) │ 上下文摘要 │ 主操作区(右)      │
│ ○ 概览       ├──────────────────────────────────────────────────────────┤
│ ● 清单       │ DataToolbar 40px（清单类）：搜索·过滤(左) │ 批量操作(右)   │
│ ○ 编辑       ├──────────────────────────────────────────────────────────┤
│ ○ 历史       │ 主体：表/卡/表单（唯一允许纵向滚动的区域）                  │
│ ○ 设置       ├──────────────────────────────────────────────────────────┤
│  …           │ Footer 32px（可选）：选中 n 项·共大小·分页                  │
└──────────────┴──────────────────────────────────────────────────────────┘
```

- PanelHeader 固定不滚动；工具条随主体滚动吸顶；**页内永远只有主体一个滚动容器**（禁双层滚动）。
- 概览/设置类无 DataToolbar/Footer，骨架其余相同；编辑类（标注器/规则编辑器）主体可为"左列表右详情"二段，仍禁再嵌套分栏超过一层。
  > **D-43 实施状态（2026-09-30，真机 CDP 三档实测，dpr 1.25）**：本节骨架第一次在真窗里成形的四枚面板＝`term`/`sys`/`notes`/`vault`（其余十枚本体不动、继续挂账）。逐档实得：`PanelHeader` **48**、`DataToolbar` **40 且 `position:sticky`／`top:0`**（同屏恒恰一枚＝吸顶不叠罗汉）、`ListFooter` **32**（notes 实测 32.8＝dpr 取整差）、二级导航 **190/48/48**（窗口 1280/1000/940，与 D-42 三档逐字同值）。`[role="toolbar"]` 由 D-42 的"真窗计数 0"翻正为四枚面板累计 8 枚渲染点（term 2 视图／sys 4／notes 3／vault 1，其中 vault 与 term 的页脚在未建库、无会话态下不渲染，该两枚的实况态未走查⇒不宣已见）。**主体单滚动**在实测到滚动余量的视图上成立：term 终端会话 max 33、sys 资源监控 max 2478/2604、kvm 158/174、desktop 507，`scrollTop` 皆达 max、末块底入视界、`hOverflow` 全 false；壳层 `work{minHeight:0}`（D-42 挂账）由此清偿。**两处如实偏差**：① 本节"主行高"未落地——清单行几何众数实测 sys 40／desktop 35／kvm·term·vault 20，`ROW_H.base`(48) 的真实落点只有 PanelHeader 与 SwitchSetting（twoline 档 64），按用户裁决"保持高密度"不复制样张的 48，行高档归各面板批按 9 节三档阶梯逐枚重定；② 面板内**能力卡**（`src/components/CapabilityCard.tsx`，渲染在 PanelHeader 与工具条之间、壳层单点）是本文与样张都没有的新增件、非对拍项——它承载"这个面板能做什么／尚不做／上限与截断／快捷键"，默认折叠为一行且首帧永不自动展开（用户明令零首启引导）。机理、偏差与挂账全貌见 `docs/DECISIONS.md` 的 D-43 实施记录。

## 2. 间距与栅格（Fluent tokens 白名单）

- 间距只允许 `color/spacing` 系列中的 **4 / 8 / 12 / 16 / 24**；同层元素间距必相同（卡片墙禁"有的 12 有的 14"）。
- 卡片内边距 16；卡片间距 16；表单分组间 24 + Divider + 组标题；分组内字段间 12。
- 内容区左右留白 20（现各面板 Root padding 对齐之，禁各写各的）。
- 表列宽：文本列弹性（min 120），数字/日期/状态列固定（延迟 `--` 占位防抖宽）；长文本 ellipsis + title tooltip，**永不折行撑高行**（例外：详情抽屉）。

## 3. 控件规范（宽度档位与选型表）

| 场景 | 控件 | 档位 | 纪律 |
|------|------|------|------|
| 单行输入 | Input | S=120（数字/端口）/ M=240（名称）/ L=360（路径/URL）/ XL=fill（搜索） | 数字类禁 XL（输入框宽度=内容量级，防"超宽空框"）|
| 枚举 ≤5 项 | RadioGroup / Tab（互斥视图用 Tab） | — | 禁 Dropdown 装 3 个选项 |
| 枚举 >5 项 | Dropdown（选）/ Combobox（可输） | M/L | 选项含计数时用 "名称（N）" |
| 开关 | Switch + 标签 + 说明行 | 全宽行 | 见 §6 SwitchSetting |
| 数值阈值 | NumberField（步进）/ Slider（连续） | 固定 160 含后缀单位 | 单位写进 suffix，禁"（分钟）"悬在框外 |
| 路径选择 | PathPicker（Input+浏览按钮） | L | 禁逼用户手打绝对路径（本仓现病：editor PDF 三框）|
| 操作按钮 | Button | 高 32；图标按钮 24/28 | 文字按钮 ≤6 字，超出即文案缺陷 |
| 破坏性 | outline + `danger` | — | 永不与主操作相邻同组（中间必有 Divider 或换区）|

- 同一工具条按钮组右对齐时主操作**恒最右**；对话框按钮恒右下：`[取消] [保存/确认]`，全应用无镜像。
- 行内操作 ≤3 个直出 + "…"溢出菜单；超过 3 个全进溢出菜单（行 hover 才显操作钮，静态占位宽防抖）。
- 一切图标按钮必带 tooltip（含无障碍名）。

## 4. 逻辑通畅四律（"点了要有下文"）

1. **反馈三件套**：每个写操作必落其一——toast（轻）、行内状态变化（列表类）、跳转结果位（长任务→传输/历史页）；零反馈=缺陷，验收按此判。
2. **禁用必解释**：disabled 控件必附 tooltip 说明原因与解锁路径（"内核未运行，先到总览启动"），禁裸禁用。
3. **表单校验时序**：字段级 inline 错误（字段下方 `aria-describedby`），提交时滚动并聚焦第一错误；异步查重（重名/端口占用）在 blur 触发而非 submit 才报。
4. **加载与空态诚实**：主体区加载用与真实布局等高的 skeleton（防 CLT 跳动，D-18 基线延伸）；EmptyState 必含"为什么空 + 第一步动作"（空搜索≠空库两文案）；错误态含 重试/查看日志（D-18）。

## 5. 清单类统一（DataToolbar 细化）

- 左区：搜索（XL→M 自适应）→ 过滤芯片（可移除、显示计数）→ 排序 Dropdown；右区：批量操作钮组（选中>0 才亮，附"已选 n"）→ 新建主按钮（最右、primary）。
- 分页与虚拟滚动二选一：>200 行必虚拟滚动（剪切板 U4 行高修正教训：行高常量单一来源）；筛选态必显示"n / 共 m"。
- 行选中模型统一：单击=选中/展开详情（详情抽屉/内联，按各档定），双击=主语义（粘贴/打开），Ctrl 多选，禁"单击就触发不可逆"。

## 6. 设置页规范（每模块"设置"子面板共用组件族）

- 每行=SwitchSetting：`[标题(粗) + 说明行(灰,可含变量)] —— spacer —— [控件右端定宽]`；同页所有行控件右缘对齐同一基线（摆整的核心：**末端对齐**）。
- 分组顺序=**前置依赖在前**（先"启用 X"开关组，后 X 的参数组；参数组在 X 关时折叠而非禁用整段）。
- 每分组右上角"恢复默认"（ConfirmDialog）；每设置项悬停 tooltip 含当前值与"生效方式"（即时/需重启内核/需重开窗口）。
- **设置归位纪律**（README §0.2）执行细则：功能区原地曾有的设置迁走后，原位置留 gear 图标"打开相关设置"直达对应子面板锚点（防"我的按钮去哪了"）。
- schema 单源：宿主设置中心与模块设置子面板读同一 schema（B0 修复 moduleId 后成立），字段 id 即锚点 id。

## 7. 锦上添花（设置体验层，随 B0/B1 逐步交付）

1. **设置搜索**：设置中心顶部一框搜全模块 schema 字段（标题+说明+路径分词），结果行=面包屑式"模块 › 分组 › 字段"点击直达锚点。
2. **最近更改**：宿主记录"我改过什么设置"时间线（含旧值→新值、一键回退）——设置多了之后的导航刚需。
3. **配置包导出/导入**：全应用设置 zip（schema 值+模板+片段+规则），**红线负例**：不含凭据/私钥路径明文/updater 相关；导入走 diff 预览再确认。
4. **首次使用导览**：全新配置首启时按模块给 3 步内引导（截图热键/代理导入订阅/密码库解锁），可整体跳过且不再出现；解决"面板很多不知从何用起"。
5. **诊断快照**：设置中心底部"复制诊断信息"（版本/模块状态/端口占用，脱敏）——报障不再截图打字。

## 8. 可判定化（本规范的回归形态）

- 组件级 vitest：SwitchSetting 行控件右缘基线、按钮顺序（对话框主操作恒最右）、disabled 必带 title 的组件测试各一条（含负例样本）；
- eslint/stylelint 侧：spacing token 白名单（出现非 §2 数值即 warning→error 渐进）；
- 每面板档 §6 验收点引用本文条款号，实启冒烟加一条"骨架走查"：任一面板滚动容器 ≤1、工具条左右区摆放与 §5 一致。

## 9. 三审增补（UI 案例调研吸收，2026-09-19，来源见 90-research-system-ui.md §2）

1. **字号阶梯表（Win11 type ramp）**：Caption 12/16（表头、辅助说明）、Body 14/20（正文缺省）、BodyStrong 14/20 Semibold（分组标题）、Subtitle 20/28（PanelHeader 标题）、Title 28/36（概览大数字）；**正文最小 14px、任何文字最小 12px；标题用 Semibold 禁 Bold**；设置/说明类长文行长 45–75 字符（超宽窗体由 §9-② 列宽上限保证）。
2. **设置页与详情抽屉列宽上限**：纯文字设置流单列，**内容最大宽 1040px 居中**（Fluent app settings 1000–1100 取中），16:9 宽窗上信息不"摊大饼"。
3. **行高三档定值**：紧凑表格行 **48**、单行列表（图标16）44、双行列表（图标/头像 32–48）64；表头 Caption 12px+浅底+padding 12——补强 §5"行高单一来源"的具体数值。
4. **每分组可见项 ≤5**：低频项折叠进 SettingsExpander 式行卡（父行=标题+摘要，展开=子选项），**嵌套恒 ≤1 层**；关断的参数组用折叠（§6 既有条款的组件名定档）。
5. **设置搜索交互**：Ctrl+F 呼出 §7-① 设置搜索（宿主级快捷键），输入即出建议 flyout；**结果 >5 条进"全部结果"整页**（PowerToys 0.94 同款），结果行含"模块 › 分组 › 字段"面包屑。
6. **项级恢复默认**：每设置项 `…` 溢出菜单含"恢复默认（当前值→默认值）"，与 §6 组级恢复默认并存两级（VS Code 心智）；默认值来自 schema 单源，禁前端另表。
7. **banner 语义分工**：内联横幅**只承载状态告警**（内核未运行/磁盘将满/漂移提醒）；破坏性动作确认恒走 ConfirmDialog（D-18）——两条通道不混用，防"横幅疲劳"。
8. **双栏断点**：清单+详情二段布局在内容区 <640px 时降级为"列表/详情二选一+返回"（Fluent list-details 官方断点），≥640 并排；详情面板选中即更新，禁"点行再点打开"两步。
9. **即时生效与保存制式**：设置类修改**即时生效，页面无"应用/确定"钮**（Fluent/WT 一致）；表单类（新建实体/编辑条目）保留 `[取消][保存]`（§3）——两制式不混：同屏禁出现"设置行 + 底部应用钮"组合。
10. **About 区制式**：宿主"关于与更新"置底一行（图标+名称+版本），展开含诊断快照/依赖/法律链接（§7-⑤ 同位置合并）。
11. **二值控件选型备注**：维持 Switch（Fluent 官方立场）；Windows Terminal 新版改 CheckBox 一事记为**已评估不采纳**（防后续贡献者再度翻烙饼）。
12. **accent 用度**：强调色只标"当前选中/可交互/状态高亮"三类，正文对比 ≥4.5:1（WCAG/Fluent a11y）；浅深主题均用 Fluent 自动生成的对比版本，禁手调色值入 token。

## 10. 四审增补：缩放与自适应重排纪律（2026-09-19，用户点名"UI 在缩放前后位置变动问题"；证据与来源见 91-research-panels-scaling.md §4）

> 现状锚点：主窗 `1280×800 / minWidth 940 / minHeight 600`（src-tauri/tauri.conf.json:17-20）；Fluent v9 令牌为 px 制；Tauri v2 已提供 `scaleFactor()/Webview.setZoom()/onScaleChanged`；覆盖层已做 `CSS px × dpr` 换算（src/windows/OverlayShot.tsx）。三条最可能漂移根因（须实测确认）：①覆盖层 CSS px 与物理 px 混用且 scale-changed 后未重算；②minWidth 940 落在 WinUI Medium 断点内却无该档确定形态；③列表/设置页未预留 scrollbar gutter，条目增减整页左右漂移。

1. **单位单一真相**：UI 侧一律 CSS 逻辑 px；跨窗口/屏幕/注入 API 必经 `scaleFactor` 显式换算，变量名带 `logical/physical` 后缀，布局代码禁出现裸物理值。
2. **"4 的倍数"从间距扩到尺寸与偏移**：宽/高/行高/边距/锚点偏移恒为 4 的倍数（Windows 缩放平台 100–400% 中 4 是唯一全乘得整的基元），文本字号豁免（走 §9-1 阶梯）。
3. **断点恒按窗口可用宽度判**（非物理屏宽）：Small <640 / Medium 641–1007 / Large ≥1008（WinUI 官方三档）；本仓一切"双栏降级/侧栏折叠/工具条折叠"阈值只用这三个数。
4. **侧栏三态**：≥1008 全栏 190px；641–1007 图标窄栏 48px（tooltip 承载名称，等价 NavigationView Compact）；≤640 收进汉堡抽屉。禁 CSS 硬压出第四种形态。
5. **minWidth 与断点自洽**：940 落在 Medium 档，须为 940–1007 定义确定形态（窄栏 SubNav + 折叠工具条 + 双栏二选一）；"把主窗 minWidth 抬到 1008"作为 B0 备选一并提交裁决，二选一后写进 tauri.conf 与本文一致。
   > **D-42 裁决（2026-09-29 用户选推荐档）：取"保持 minWidth 940 ＋ 实现 Medium 档 48px 图标窄栏"，`src-tauri/tauri.conf.json:17-20` 数值不改**，故本条的二选一已闭合、无需再抬窗口下限。算术依据是在册风险 `docs/REVIEW-2026-09-18.md:115`：940−主导航 228−二级导航 190＝522px 内容区（裁切），窄栏后 940−228−48＝664px。落地形态＝`src/styles/global.css` 的 `[data-nf="work"]` container query（≤1007px 二级导航收 48px、条目文字 1em 裁切留首字并以按钮 `title` 承载全名——SUBNAV 条目无图标集，整体隐藏会留下一条不可辨识的空栏；≤640px 整栏 `display:none` 收除，本仓不做汉堡抽屉，与第 4 条的"汉堡"一档留差），判据走自定义属性下发而非 griffel 哈希类（`src/layout/SubNav.tsx` 读 `var(--nf-subnav-w, 190px)` 等四枚，机理与门禁见 `src/layout/__tests__/layoutCompliance.test.ts` 与 tools/assert-patterns.ps1 的 D-42 扫描）。**真机三档实测**（2026-09-29 CDP 直连真窗，dpr 1.25）：窗口 1280/1000/940 ⇒ 容器 1052/772/712 ⇒ 二级导航实得 190/48/48、内容区实得 862/724/**664**；700 档容器 561 时整栏收除。本条剩余的"折叠工具条/双栏二选一"未在 D-42 壳批范围，归各面板批；工具条不换行的纪律由 DataToolbar 的 `flexWrap:"nowrap"` 承担。
   > **D-43 追记（2026-09-30 真机走查抓出的窄栏缺陷，档位纪律补一条）**：Medium 档不只管二级导航——**面板内的多列栅格同档必须有确定形态**，且 `1fr` 轨道必须给非零底。机理实测：`NotesPanel` 三列工作台把中间编辑核写成零底的 `1fr`，容器 772/712 时列宽实测塌成 **92px／16.8px**，正文竖排成一根 693.6px 高细列（同批容器 1052 时正常 230px）。治法与 subnav 同谱＝列宽档经 `--nf-split-cols` 由 container query 下发（宽档三列 `220–300 / ≥240 / 180–260`，Medium 档收两栏、第三块由网格换行），修复后实测 1280＝295/240/255、1000＝300/368、940＝300/308 且无横向溢出。门禁＝`layoutCompliance.test.ts` 的零底轨道源扫＋`tools/assert-patterns.ps1` 的下发侧两档齐（变量出现次数 <2 即红，防"覆写被摘、宽档独留"的半死形态）。**教训**：三档对拍过去只量二级导航，列宽无人量——窄栏走查必须逐档量列组成，jsdom 与源扫都看不见塌陷。
6. **DPI/尺寸变更后派生值全部作废**：`onScaleChanged`/`onResized` 到达即重算——虚拟列表测量、canvas/缩略图/标注层/图谱位图、覆盖层坐标映射、贴图物理位置；禁在模块初始化期缓存 scaleFactor 派生数据（位图必须重栅格化而非拉伸）。
7. **DPI 变化时窗口几何采用系统建议矩形**：禁"读 outerSize 再回写"的自校正实现（官方明示会造成鼠标相对位置漂移与递归 DPI 变更循环）。
8. **分数缩放下 1px 线不承载层级**：分隔/边框厚度须可被 scaleFactor 整除（125%/150% 下 1px 重采样成灰带/半线）；主视觉层级改背景色带或 2px。
9. **应用内缩放用 webview zoom，禁全局 `transform: scale()`**：`setZoom`（WebView2 ZoomFactor）参与布局重算、文字边框同尺度；transform 不改盒→溢出裁切，只允许用于局部动效。
10. **缩放二态且不互覆**：设置中心提供"整体缩放（zoom，档位 100/110/125/150/175/200% 对齐 Windows 平台，按窗持久化+重置 100%）"与"仅放大字体（字号令牌，§9-1 阶梯整体上移）"两个独立开关（VS Code zoomLevel/fontSize 二分心智）；`webview:allow-set-webview-zoom`  capability 显式登记 + security_config 兜底负例（辅助窗不得持有）。
11. **OS scale 与 app zoom 是两条独立乘数**：任何按物理像素工作的功能（截图选区、贴图位置、KVM edge_map、DPI 检测、覆盖层居中）代码与注释必须声明所用维度，最终视觉倍率=两者乘积；`CSS×dpr` 换算须考虑 zoom 生效后的 innerWidth 变化。
12. **滚动条槽恒预留**：主体唯一滚动区、表头、详情抽屉、1040px 居中设置页一律 `scrollbar-gutter: stable`（居中页配 `both-edges`）——杜绝"筛选后条目变少→滚动条消失→整页右移"。
13. **滚动锚定显式化**：虚拟列表恢复按"锚点行 index + 行内 offset"而非 scrollTop；实时流（终端输出/事件检查器/共享历史）显式 `overflow-anchor: none`，长文/历史保留 auto；resize/zoom 后按锚点行重设偏移，**滚动位置在缩放前后不得跳**。
14. **虚拟列表行高以逻辑 px 下发不乘 dpr**（§9-3 三档），测量结果不回写常量；zoom 变更后同步 overscan（≥3 行），行高常量单一来源纪律延伸自剪切板 U4 教训。
15. **防抖宽与折叠次序**：数字/时间/计数/延迟列恒 `font-variant-numeric: tabular-nums` + 右对齐定宽（`--` 占位既有纪律不变）；宽度不足时折叠次序恒为"搜索框 XL→M → 次级按钮进 `…` → 主按钮永不折叠 → 标题 ellipsis"，**禁工具条换行**（换行=行高变化=整页重排）；940/1008/1400 三档 vitest 快照回归。
16. **命中区与对比度不随密度缩水**：紧凑态（图标窄栏/行高 44）交互目标仍 ≥40×40 逻辑 px（不足者透明 padding 扩 hitbox，不缩视觉尺寸）；`forced-colors: active` 下禁以 1px 边框表达层级，`prefers-contrast: more` 分隔线升 2px；preview 样张加"三档宽度 × 高对比"缩放自检对拍。
