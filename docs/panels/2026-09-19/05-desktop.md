# 05 桌面效率面板详细设计（B1 接线 + 深化）

> 总纲：docs/impl/09 §4/§7；对标蓝本无专节（DESIGN "桌面效率"自立项），参考软件取 uTools/Quicker/PowerToys Run/Flow Launcher/Everything；状态：未开工。

## 1. 现状问题

- 启动器区块是**纯说明文字 + 就绪 Badge**，无任何按钮——`desktop_launcher_search/launch` 后端与 LauncherWindow 都在，主面板零入口（勘查 D1）。
- `desktop_notes_due`（到期主动查询）孤儿：提醒只靠 `desktop.remind_due` 事件路过，面板打开时看不到"现在已到期哪些"。
- 桌面整理：分类/目标为固定策略，无用户规则编辑（分类→目标夹映射、排除清单）；整理历史不可追溯。
- 待办无到期视图/无顺延；随记 #标签有了但无过滤。
- 一屏竖排四区块，无子导航。

## 2. 子面板信息架构

| 子面板 | 类型 | 内容 |
|--------|------|------|
| 概览 | 概览 | 今日到期待办卡 + 桌面文件数/上次整理 + 启动器热键提示 + 快捷动作 |
| 待办 | 清单 | 列表（今天/计划/已完成三段）+ 到期时间编辑 + 顺延/完成/删除 + #标签过滤 |
| 随记 | 清单 | 速记流（时间倒序卡片流，非表格）+ 标签过滤 + "转为笔记"（→notes 模块）|
| 整理 | 编辑 | 规则编辑器（类型→目标夹映射表，可增删行）+ 排除清单（文件名/夹）+ 预览/执行/还原 + 历史（tidy 事件列表）|
| 启动器 | 清单+编辑 | 内嵌搜索框（实调 search 命令，回车启动）+ 最近使用 Top + 别名表（拼写纠正/自定义词→条目）+ 应用/文件夹/URL 三类固定项管理 + "打开启动器窗"按钮 |
| 设置 | 设置 | 启动器快捷键说明与冲突检测、索引重建按钮、整理自动周期（联动 automation）、提醒提前量 |

## 4. 其他软件借鉴

- **PowerToys Run**：结果行右侧显示类型角标（应用/设置/操作），"动作"键（Ctrl+ 切换打开位置/以管理员运行/复制路径）——启动器结果行的信息架构；
- **Flow Launcher**：Web shortcut 自定义（`gh {query}` → GitHub 搜索）——URL 固定项带 `{q}` 模板即得；
- **Quicker**：「鼠标滑过取词」不做（过重），但借鉴其"动作运行结果浮窗"→ 启动器结果 toast；
- **Everything**：函数式搜索语法子集（`ext:` `size:`）若 launcher 索引含文件则顺带支持，否则不承诺（文案纪律：面板承诺=已接线）。

## 5. 拓展设计（常人未思）

1. **计算即结果**：启动器输入 `1280*720/24`、`10 USD->CNY`（离线汇率表周更或 DeferredBadge）、`#FF8800`（色彩预览行）——纯前端求值小解析器，PowerToys 验证过的最高频轻功能。
2. **时段建议**：本地统计启动器使用（app→时段直方图），概览页"早上常开"卡一键固定——零云、纯本地，典型"没人给桌面整理工具做"的体贴。
3. **整理undo 时间线**：每次 apply 落清单（哪些文件从哪到哪），restore 前可视化 diff——防"整理把我的东西藏哪了"恐慌。
4. **随记→笔记→待办三向流转**：卡片右键互转（跨模块桥，数据已有语义缺通路）。
5. **提醒汇聚**：待办到期 + 密码库自动锁警告 + 同步冲突 统一进宿主通知中心（15-host-shell 通路），桌面效率模块作为最大提醒源。

## 6. 验收点

- 启动器面板搜索真实返回并启动（实启冒烟）；别名 round-trip；
- `desktop_notes_due` 接线（无事件也能看到到期项）；
- 整理规则自定义 → plan 输出随规则变（测）；排除清单生效负例；
- 新命令一律 permissions+capability 同步；文案承诺与接线表交叉断言（README §0.4 纪律）。
