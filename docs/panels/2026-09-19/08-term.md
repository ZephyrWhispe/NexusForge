# 08 终端运维面板详细设计（B1 接线 + B7 深化）

> 总纲：docs/impl/09 §7；对标：NyaTerm（蓝本 §3.11）+ WindTerm/MobaXterm/Tabby；§5"端口转发/跳板机"行已被 D-29 取代提前入本档；状态：未开工。

## 1. 现状问题

- **会话即抛**：SSH 每次填表单，无保存会话/分组/别名（WindTerm/NyaTerm 第一卖点即 session 管理器）；凭据手输或私钥路径，无 vault 联动。
- `term_ssh_known_hosts`/`term_ssh_forget_host` 孤儿：TOFU 指纹记录看不见删不掉（主机密钥变更只能改盘）——安全功能藏进文件系统。
- 端口转发 -L/-R/-D 与 ProxyJump 全缺（grep 0 命中）；SFTP 只有 list/下载/上传（无删除/改名/建目录/权限位）；Docker 只有 containers+lifecycle+logs（无 exec/镜像/卷/网络）。
- 终端区无分屏、无滚动搜索（xterm 有现成 addon）、无命令片段库。
- 表单堆叠在会话页顶部——"新建连接"永远是主角，高频用户每天重复填表。

## 2. 子面板信息架构

| 子面板 | 类型 | 内容 |
|--------|------|------|
| 会话 | 清单 | 会话档案树（分组：本地/WSL/SSH/Docker + 用户自建组）：名称/主机/用户/认证方式/上次连接/**凭据来源（vault 条目标记）**；双击即连；新建/编辑抽屉表单；"最近连接"Top |
| 终端 | 编辑 | 现 xterm 区 + 分屏（横/纵二分递归）+ 滚动内搜索（fit+webgl+search addon）+ 片段侧栏（见下）+ 重连按钮（网络恢复事件自动重试策略）|
| 文件 | 清单 | SFTP 双栏（本地|远端）+ 写操作（mkdir/delete/rename/chmod——远端删除确认输入路径，无回收站红线补强）+ 传输队列（复用 file 队列 UI 语言）|
| 端口转发 | 清单+编辑 | 隧道表（类型 L/R/D、本地口/远端口/目标、状态灯、启停）+ 归属会话；冲突检测预填 |
| Docker | 清单 | 容器（现状）+ **exec 进容器终端**（复用会话基础设施）+ 镜像/卷/网络三页（Engine API HTTP 调用，只读+删）|
| 主机信任 | 清单 | known_hosts 表（主机/算法/指纹/首次时间）+ 删除 + **指纹变更事件红条**（TERM_SSH_002 触发时导向此页）|
| 片段 | 清单+编辑 | 命令片段库（名称/命令/说明/分组/风险级）+ 一键发送到当前或全部选中会话 |
| 设置 | 设置 | 字体/主题（跟随宿主 or 独立配色）/回滚行数/确认策略/录音开关 |

## 4. 其他软件借鉴

- **WindTerm**：连接成功后自动执行"启动命令组"（会话档案 advanced 字段）；SFTP 与终端**同目录双向跟随**（cd 联动）；
- **MobaXterm**：拖文件到终端行=上传到当前路径（xterm drop 处理）；
- **Tabby**：设置即 JSON 可编辑视图（本模块设置走 host_config 即可，记此纪律避免双轨）；
- **Termius**：片段的变量占位 `{{host}}`——渲染时从会话档案注入（本地展开，绝不联网同步）。

## 5. 拓展设计（常人未思）

1. **命令风险分级**：片段与手动执行匹配危险模式（`rm -rf`、`dd of=/dev/`、`mkfs`、`shutdown`、管道到 sh）→ 红条 + 输入确认；误报可"本次放行"——终端模块的安全纵深，WindTerm 无。
2. **广播模式**：选中多会话→同输入（运维改 N 台机器），激活时全屏红边框常驻，Esc 全退——MobaXterm 有但形态粗糙，做实确认面。
3. **会话录制**：asciinema cast 格式本地落盘（含时间轴）+ 面板内回放/导出——审计与复盘双价值，格式开放不锁死。
4. **凭据联动**：会话档案可选"密码来自 vault 条目"引用——解锁库后一键填充，锁定即不可得（vault×term 跨模块，红线：内存中密码用后清零）。
5. **隧道即节点**：`-D` 动态转发建立后提示"是否把代理模块 SOCKS 上游指向本隧道"——SSH 跳板机出网与 proxy 模块的桥（登记为提示联动，不做自动改配置）。

## 6. 验收点

- 转发三型 e2e（本地回环靶）+ 端口占用冲突负例；ProxyJump 双跳均校验指纹（断言拒连路径）；
- SFTP 删除：确认词输入 + 失败不级联；广播模式激活断言不可无确认；
- 录制文件回放正确（cast 解析单测）；凭据 vault 引用不落盘明文（档案 JSON 序列化负例）；
- known_hosts 删除当前活跃会话主机 → 拒绝或警告（勘查定）；新命令 permissions+capability 全同步。
