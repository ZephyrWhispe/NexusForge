# 08 终端运维面板详细设计（B1 接线 + B7 深化）

> 总纲：docs/impl/09 §7；对标：NyaTerm（蓝本 §3.11）+ WindTerm/MobaXterm/Tabby；§5"端口转发/跳板机"行已被 D-29 取代提前入本档；状态：未开工。

## 1. 现状问题

- **会话即抛**：SSH 每次填表单，无保存会话/分组/别名（WindTerm/NyaTerm 第一卖点即 session 管理器）；凭据手输或私钥路径，无 vault 联动。
- `term_ssh_known_hosts`/`term_ssh_forget_host` 孤儿：TOFU 指纹记录看不见删不掉（主机密钥变更只能改盘）——安全功能藏进文件系统。
- 端口转发 -L/-R/-D 与 ProxyJump 全缺（grep 0 命中）；SFTP 只有 list/下载/上传（无删除/改名/建目录/权限位）；Docker 只有 containers+lifecycle+logs（无 exec/镜像/卷/网络）。
- 终端区无分屏、无滚动搜索（xterm 有现成 addon）、无命令片段库。
- 表单堆叠在会话页顶部——"新建连接"永远是主角，高频用户每天重复填表。

## 2. 子面板信息架构

| 子面板 | 类型 | 内容 |
|--------|------|------|
| 会话 | 清单 | 会话档案树（分组：本地/WSL/SSH/Docker + 用户自建组）：名称/主机/用户/认证方式/上次连接/**凭据来源（vault 条目标记）**；双击即连；新建/编辑抽屉表单；"最近连接"Top |
| 终端 | 编辑 | 现 xterm 区 + 分屏（横/纵二分递归）+ 滚动内搜索（fit+webgl+search addon）+ 片段侧栏（见下）+ 重连按钮（网络恢复事件自动重试策略）|
| 文件 | 清单 | SFTP 双栏（本地|远端）+ 写操作（mkdir/delete/rename/chmod——远端删除确认输入路径，无回收站红线补强）+ 传输队列（复用 file 队列 UI 语言）|
| 端口转发 | 清单+编辑 | 隧道表（类型 L/R/D、本地口/远端口/目标、状态灯、启停）+ 归属会话；冲突检测预填 |
| Docker | 清单 | 容器（现状）+ **exec 进容器终端**（复用会话基础设施）+ 镜像/卷/网络三页（Engine API HTTP 调用，只读+删）|
| 主机信任 | 清单 | known_hosts 表（主机/算法/指纹/首次时间）+ 删除 + **指纹变更事件红条**（TERM_SSH_002 触发时导向此页）|
| 片段 | 清单+编辑 | 命令片段库（名称/命令/说明/分组/风险级）+ 一键发送到当前或全部选中会话 |
| 设置 | 设置 | 字体/主题（跟随宿主 or 独立配色）/回滚行数/确认策略/录音开关 |

## 4. 其他软件借鉴

- **WindTerm**：连接成功后自动执行"启动命令组"（会话档案 advanced 字段）；SFTP 与终端**同目录双向跟随**（cd 联动）；
- **MobaXterm**：拖文件到终端行=上传到当前路径（xterm drop 处理）；
- **Tabby**：设置即 JSON 可编辑视图（本模块设置走 host_config 即可，记此纪律避免双轨）；
- **Termius**：片段的变量占位 `{{host}}`——渲染时从会话档案注入（本地展开，绝不联网同步）。

## 5. 拓展设计（常人未思）

1. **命令风险分级**：片段与手动执行匹配危险模式（`rm -rf`、`dd of=/dev/`、`mkfs`、`shutdown`、管道到 sh）→ 红条 + 输入确认；误报可"本次放行"——终端模块的安全纵深，WindTerm 无。
2. **广播模式**：选中多会话→同输入（运维改 N 台机器），激活时全屏红边框常驻，Esc 全退——MobaXterm 有但形态粗糙，做实确认面。
3. **会话录制**：asciinema cast 格式本地落盘（含时间轴）+ 面板内回放/导出——审计与复盘双价值，格式开放不锁死。
4. **凭据联动**：会话档案可选"密码来自 vault 条目"引用——解锁库后一键填充，锁定即不可得（vault×term 跨模块，红线：内存中密码用后清零）。
5. **隧道即节点**：`-D` 动态转发建立后提示"是否把代理模块 SOCKS 上游指向本隧道"——SSH 跳板机出网与 proxy 模块的桥（登记为提示联动，不做自动改配置）。

## 6. 验收点

- 转发三型 e2e（本地回环靶）+ 端口占用冲突负例；ProxyJump 双跳均校验指纹（断言拒连路径）；
- SFTP 删除：确认词输入 + 失败不级联；广播模式激活断言不可无确认；
- 录制文件回放正确（cast 解析单测）；凭据 vault 引用不落盘明文（档案 JSON 序列化负例）；
- known_hosts 删除当前活跃会话主机 → 拒绝或警告（勘查定）；新命令 permissions+capability 全同步。

## 7. 排版方案与二审补充（2026-09-19 复审）

### 7.1 排版方案（逐子面板）

- **会话**：左侧档案树（220px 固定，分组可折叠）+ 右侧详情/最近连接；树行 `[状态点：连接中/上次失败/未连][名称][主机:端口副行]`；双击即连是主路径，"新建"按钮在 DataToolbar 右端；编辑为右侧抽屉（00§2 与 vault 详情抽屉同规格），表单分组=连接（主机/端口/用户）→认证（方式 Radio 换组重渲染：密码/vault 引用/私钥路径，00§3 禁手打路径用 PathPicker）→高级（jump 选择、启动命令组、隧道表嵌入）。
- **终端**：分屏格为主体，标签条 36px（每标签=一组分屏布局）；片段侧栏可折叠 280px；滚动搜索条浮于右上（Ctrl+F，匹配计数）；广播模式激活时顶部红条常驻+"退出广播 Esc"（§5-② 的确认面）。
- **文件**：双栏各 50%，栏内 `[向上][刷新][路径面包屑]` 栏头 + 标准表行；传输队列折叠在底部 32% 高度，与 04-file 传输页同一组件语言；本地/远端 cd 联动开关放两栏中间（WindTerm 借鉴升为可配）。
- **端口转发**：表行 `[类型Badge L/R/D][本地口][目标 host:port][归属会话][状态灯][Switch][删]`；新增行追加表尾自动聚焦；冲突检测在提交前就地报错（00§4 表单校验行内下方）。
- **Docker**：容器表现状保留 + exec 行动作开新终端标签（复用会话基础设施）；镜像/卷/网络三节折叠，删除一律 destructive 确认流。
- **主机信任**：标准表 `[主机][算法][指纹等宽可截断][首次时间][删除]`；TERM_SSH_002 红条横幅居页顶并深链到此（00§6 gear 锚点纪律的反向用法：事件→页）。
- **设置**：SwitchSetting 行制；分组序=外观（字体/主题）→行为（选中即复制/右键粘贴/回滚行数）→确认策略→录制。

> **D-43 实施状态（2026-09-30，C5 落地＋真机实测）**：终端会话/Docker 两枚互斥视图由 `<Tabs>` 上移左轨（视图键 `termTab`），会话切换与启动入口进**一枚吸顶 `DataToolbar`**（实测高 40、`sticky`、`top:0`），首层三区块各立标题，会话清单与 SFTP 清单的内层视口收敛为主体单滚动＋分页页脚（"共 N 项 · 在场 M 项＋显示更多"），转发表两枚原生 `checkbox` 换 Fluent `Checkbox`。真机实测：终端会话档滚动面 max **33**、`scrollTop 32.8`、末块底 748 入视界；Docker 档"内容不足一屏"。**本小节"Docker 日志输出面"的第二滚动容器有意保留**（日志随 tail 增长，无自留视口会把整页撑长），故本面板不宣"全档单滚动"，只在实测视图上宣。未做＝档案树 220px＋状态点、分屏格与 36px 标签条、片段侧栏 280px 可折叠、双栏文件与传输队列、广播模式红条、jump/隧道表嵌入——会话档案与片段库持久化需新 Rust 命令。

### 7.2 配套功能缺口（二审新增）

1. **SSH keepalive + 自动重连**：会话即抛问题（§1）的孪生缺口是"连上了又掉"——档案 advanced 字段加 keepalive 间隔、自动重连开关（指数退避封顶），重连成功后**自动恢复该会话名下已启用的隧道**并提示"转发已重建"；不做则端口转发功能在真实网络下不可依赖。负例：手动断开不触发重连（区分用户意图与链路故障）。
2. **复制粘贴个性开关**：终端用户两大肌肉记忆配置（选中即复制、右键粘贴/右键菜单）入设置——缺省时右键=菜单，开启后右键=直接粘贴并在 tooltip 说明改回方式；这是 Tabby/Windows Terminal 都提供的最小尊重。
3. **隧道与会话生死绑定**：转发表的状态灯必须真实反映"归属会话已断→隧道已死"（含 §7.2-① 重连后恢复）；孤儿隧道（会话档案已删）在表中红字标记并可一键清理。
4. **SFTP cd 联动升矩阵行**：§4 WindTerm"同目录双向跟随"从借鉴段升为 §3 矩阵第 13 行（实施=终端 OSC cwd 事件不可得时降级为手动"同步到终端目录"按钮，勘查登记，禁假承诺）。
5. **会话档案导出/导入**：只导结构不导秘密（凭据 vault 引用按目标机重映射或置空，导出预览明示将包含什么——00§7-③ 配置包红线同源，负例：导出 JSON 全文无密码与私钥内容）。
6. **shell integration 评估**：命令开始/结束/退出码的 OSC 133 标记决定 §5-① 风险分级与录制打点的精度——列入 B7 勘查项，缺则相关功能按"不承诺精确"文案降级。

### 7.3 锦上添花

1. **断开原因一句话**：连接失败 toast 不说"SSH 错误"而说"认证被拒/网络不可达/主机指纹变更"三分型导向（各自跳向对应设置/信任页）——错误信息的可操作性是终端工具的口碑线。
2. **片段变量补全**：`{{host}}` 输入时下拉提示会话档案可用变量（§4 Termius 借鉴的编辑器化呈现）。
3. **录制打点书签**：回放时间轴上按"高风险命令确认"自动生成书签跳帧——复盘时长从分钟级到秒级。
