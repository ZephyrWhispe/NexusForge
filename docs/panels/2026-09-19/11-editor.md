# 11 文本与 PDF 面板详细设计（B1 接线 + B7 深化）

> 总纲：docs/impl/09 §7；对标：蓝本 §3.5 + VS Code/Notepad++ + Stirling-PDF；状态：未开工。基础面已不薄：Monaco 多标签、>5MB/>50MB 降级策略（EditorPanel.tsx:37）、3s 防抖 autosave、PDF 五操作全接线、D-18 原地改写确认——本档解决"最后一百米"与深度差距。

## 1. 现状问题

- **editor_save_as 孤儿**：后端完整（commands/editor.rs:64 → session.rs:203 复制+清 autosave），前端零调用；另存为只能"手改路径再保存"。
- **一切路径靠手打 Input**：PDF 区 `pdfPath/pdfInputs/pdfOut` 三个文本框（EditorPanel.tsx:325-327）手输绝对路径；全仓无 `@tauri-apps/plugin-*` JS 调用（D-28 勘查事实）——**引入 tauri-plugin-dialog 是新增依赖决策，开工时先补 D-30 条目 + permissions/capability 同步**。
- **草稿箱"只写不看"**：autosave 文件（`.nforge-autosave`，session.rs:16/226）崩溃后无人知晓——会话列表 `editor_sessions` 不扫描草稿，重启即"静默丢草稿感知"。
- **编码/换行只读**：encoding/EOL Badge 展示（:387-393）与混合行尾警告✅，但转码（BOM 增减、GBK↔UTF-8、CRLF↔LF 主动切换）无入口，`encode()` 后端已有（session.rs:375）。
- **无对比模式**：Monaco DiffEditor 现成能力未用（两文件/工作副本 vs 磁盘副本都看不了）。
- **PDF 面窄于 Stirling 一张卡都不算**：仅 merge/split(全单页)/compress/watermark/info；split 不支持页码范围（pdf.rs:93 恒逐页拆）；无删除页/旋转/重排/页面提取。
- 567 行单组件、单页纵向堆叠（会话+编辑器+PDF 区一屏滚）——README §0 禁令的形态。

| 子面板 | 类型 | 内容 |
|--------|------|------|

## 4. 其他软件借鉴

- **VS Code**：热退出（hot exit）心智——所有脏缓冲下次启动原样回来（草稿箱的产品化终点）；"与已保存版本比较"命令进标签右键。
- **Stirling-PDF**：工具卡按"组织/修改/压缩转换/水印安全"分组 + 最近使用置顶；批量卡（一次选 N 文件同操作）。
- **Notepad++**：编码菜单的"以 X 编码转/以 X 打开"二分（转码≠重解码，误用即乱码——下拉须把这两个动作分开呈现）；
- **WinMerge**：忽略空白/大小写比较选项——diff 设置组。
- **Raycast 快照式本地历史**（借理念不借形）：见拓展②。

## 5. 拓展设计（常人未思）

1. **本地历史快照**：每次成功保存向 `{appData}/editor/history/{hash}/` 追加带时间戳快照（滚动保留 N 份），标签右键"时间机器"列快照+逐个 diff+回滚——轻量重写恢复不靠云端；红线：vault 内导出文件/敏感模式文件名不入快照。
2. **二进制嗅探只读**：open 时前 8KB 出现 NUL/高比例不可解码字节→自动只读+提示（现状会当文本硬解），Monaco 大档保护一并触发。
3. **锚点跳转桥**：markdown 文件内 `[[笔记名]]` 链接点击→跳笔记模块对应文档（notes resolve_link 现成，编辑器只需识别+发导航事件）——文本工具升格知识工作流入口。
4. **剪贴板历史→文件**：历史条目右键"存为 .md/.txt"直落 editor 草稿箱（clipboard×editor 桥）。
5. **PDF 危险编辑红线前置**：原地压缩/水印已有 D-18 确认；新四卡涉及"删页丢失内容"——默认**另存输出**，原地模式要求确认词输入（PDF 是不可逆容器）。

## 6. 验收点

- dialog 插件引入的 D-30 登记 + permissions/capability 同步 + CSP 复核（无新源）；save_as 端到端（含 autosave 清理断言，session.rs:203 语义）；
- 草稿箱负例：无草稿时不出现幻影入口；恢复后内容=最后 autosave 而非磁盘旧版；
- `RangeSpec` 单测含畸形输入负例（"3-1"、"0"、",,"）；删页后文件大小/页数断言；
- 转码：GBK→UTF-8 round-trip 正例 + "以错误编码打开"不污染快照；diff 视图写回负例；
- 本地历史快照上限滚动 + 敏感名单负例。

## 7. 排版方案与二审补充（2026-09-19 复审）

### 7.1 排版方案（逐子面板）

- **文件**：三段折叠（草稿箱置顶且仅在有草稿时出现——负例"幻影入口"已是验收点，排版上就是条件渲染）+ 会话表行 `[脏标●][文件名+路径副行][编码/EOL 只读芯片][上次打开][打开/关闭…]`；"新建/打开"按钮在 DataToolbar 右端，打开走 native dialog（D-30 后）。
- **编辑**：标签条 36px + Monaco 满体；视图开关组收进右上角"眼镜"弹出菜单不占工具条；编码转换下拉在 Footer 状态行原位（点击弹出 Notepad++ 二分动作组：转换/重打开）；查找替换用 Monaco 内置浮动卡不新增页内栏。
- **对比**：全屏双栏 DiffEditor，栏头 A/B 文件路径 + 忽略空白/大小写芯片组；顶部横幅常驻"只读视图"角标（§2 红线的视觉化）。
- **PDF 工作台**：工具卡网格（每卡 `[图标][工具名][支持范围一行]`），分组序=读取类（信息）→组织类（拆分/删页/重排）→输出类（合并/压缩/水印/提取）；打开的 PDF 路径为页级上下文条（PathPicker 换文件），各卡共享，禁每卡重复手输（§1 病根的排版级根治）；结果流水表在网格下方折叠节。
- **设置**：分组序=编辑器外观→保存行为（autosave/大文件阈值）→默认编码与 EOL→本地历史（份数上限+敏感名单入口）。

### 7.2 配套功能缺口（二审新增）

1. **外部修改冲突检测**：编辑器面板化后成为"日常打开器"，配套刚需是**保存前 mtime 比对**——磁盘版本被外部改动时弹三选（重载/以我为准覆盖/打开 diff 对比），脏缓冲与磁盘差异直接复用 DiffEditor；不做则"本地历史快照"（§5-①）救不了"静默覆盖外部改动"这个更常见的事故。负例测试：外部写入后保存必触发确认。
2. **标签 pin / 预览态**：双击=固定、单击=预览斜体标签（VS Code 心智）——最近文件连点不炸标签条，多标签工具的隐性配套。
3. **未保存关闭拦截**：关标签/关面板窗时脏缓冲确认（"保存草稿后关闭"为缺省项——与草稿箱同一条心智，三选：保存/丢弃/取消）。
4. **只读状态显性化**：二进制嗅探（§5-②）、>50MB 降级、diff 视图三种只读态统一 Footer 灰角标 + tooltip 原因（00§4-④ 禁用必附原因在状态行的等价物）。
5. **PDF 批量卡**：§4 Stirling 批量（一次选 N 文件同操作）升配套——信息/压缩/水印三卡先支持多文件入队（结果流水表天然多行），拆分类不做批量（输出目录冲突面大，登记边界）。

### 7.3 锦上添花

1. **状态行字数统计**：行数/字数/选区字数（写作场景的肌肉记忆），纯前端。
2. **"时间机器"缩略时间轴**：本地历史快照以横向时间轴呈现而非列表——回滚决策看一眼就懂。
3. **Markdown 大纲侧栏**：md 文件自动提纲导航（Monaco 符号能力，纯前端）——文本工具向笔记桥（§5-③）的同一方向。
