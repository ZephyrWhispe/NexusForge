# 03 密码库面板详细设计（B1 接线 + 深化）

> 总纲：docs/impl/09 §4(B1)/§7；对标：Vaultwarden（蓝本 §3.3 数据模型）+ Bitwarden/KeePassXC/1Password；状态：未开工。

## 1. 现状问题

- 孤儿命令：`vault_change_master_password`、`vault_folder_rename` 后端有 UI 零入口；`vault_entry_get` 未用（编辑全靠列表缓存）。
- 搜索恒空：`vaultEntries` 的 search 参数前端永远传 null——后端过滤器白做。
- 设置缺位：自动锁定阈值/空闲检测策略无配置入口（只有事件驱动的只读倒计时 Badge）；剪贴板清除延迟不可调；解锁冷却参数不可见。
- 蓝本 §3.3 数据模型的 `Card/Identity/SSHKey` 类型与 `Attachment`：类型下拉有但无专属表单；附件后端无实现（勘查：全链无踪迹）。
- UI：编辑用 480px Dialog 全字段一滚到底；文件夹平铺无层级视觉；条目多时右侧列表无虚拟滚动。

## 2. 子面板信息架构

| 子面板 | 类型 | 内容 |
|--------|------|------|
| 条目 | 清单+编辑 | 左文件夹树（含收藏/全部/TOTP 快捷虚拟节点）+ 右条目表（虚拟滚动、类型图标、搜索框接后端）+ **详情抽屉**（占右半区，非 Dialog）：基本/自定义字段/TOTP/历史 四段 |
| 生成器 | 编辑 | 独立页：密码/passphrase/用户名/TOTP 校验；参数持久化；"填入新建条目"按钮 |
| 安全健康 | 概览 | 弱密码/重复/长期未换/无 TOTP 高危项四卡 + 列表 + 修复跳转 |
| 导入导出 | 设置 | 导入 Bitwarden CSV/JSON、KeePass XML；导出加密信封（明文导出=危险操作输入确认词） |
| 历史 | 历史 | 条目版本快照列表（KeePass history 思想）+ 库级操作审计（创建/改密/导出事件） |
| 设置 | 设置 | 自动锁定阈值（空闲分钟/锁屏触发）、剪贴板清除秒数、Hello 管理、防暴力冷却参数、虚拟键盘保护说明（VirtualLock 已在）|

## 4. 其他软件借鉴

- **KeePass AutoType**（§5-①）；**Bitwarden 收藏置顶+类型筛选芯片**：条目表顶过滤条；**1Password 紧急包**（§5-⑤）；**KeePassXC 数据库安全性页**（KDF 参数只读展示 + "更换 KDF"入口样式）→ 设置子面板加"加密参数"卡（Argon2 内存/迭代展示，改动=全库重加密警示）。

## 5. 拓展设计（常人未思）

1. **AutoType 一键登录**：选中条目按 `Ctrl+Alt+Enter` → 焦点窗口注入 `用户名 Tab 密码 Enter`（win-integration SendInput 已有；序列模板可编辑）。红线：仅显式触发后 5s 窗口内有效、锁库即失效、注入前不清其他剪贴板（负例三连）。
2. **复制倒计时可撤销**：复制密码后状态栏出现 N 秒清除进度 chip，点击"保留"取消清除（场景：还没粘贴完就被清了——所有密码管理器的共同痛点）。
3. **SSH Key 专页**：指纹列表 + 复制公钥/生成 `authorized_keys` 行/与 term 面板"用此密钥连接"联动（跨模块）。
4. **重复/泄露检测**：同密码跨条目重复簇视图；可选联网"已泄露密码"检查（k-anonymity range 查询，默认关+明示上云内容仅 SHA1 前 5 字节——红线：绝不含明文与库内容）。
5. **紧急包打印**：主密码恢复指引 + 加密库文件路径 + 校验指纹生成一页 HTML（break-glass，1Password Emergency Kit 思想）——灾难恢复心智是"简单感"面板最缺的深度。

## 6. 验收点

- 改主密码 e2e：改后旧密码登录必拒（红线负例）+ 中途失败库不破；
- 导入 Bitwarden CSV 含公式注入样本（`=cmd`）被净化（安全负例）；
- 健康检测纯函数单测（弱/重判定的正反例夹具）；
- AutoType 时序窗断言；搜索过滤参数真实下推（前端不再 filter）。

## 7. 排版方案与二审补充（2026-09-19 复审）

### 7.1 排版方案

- **条目（清单+编辑）**：左文件夹树 220px（树行=`[图标][名称][计数灰]`）+ 右条目表（虚拟滚动）。表行=`[类型图标][标题 bold][用户名 灰][URL 灰 ellipsis][收藏☆][修改时间右靠]`；行点击=右侧**详情抽屉 520px** 占右半（00§1 编辑二段例外），抽屉内四段 Tabs（基本/字段/TOTP/历史）而非一滚到底；抽屉头部动作=`[编辑][复制用户名][复制口令][…（自动type/查看历史）]`，**复制口令永远在复制用户名之后**（肌肉序防错拷）；编辑态就地展开（字段变输入框），保存/取消恒右下按钮对（00§3）。
- **生成器**：单表单居中 480px 列宽；参数组=长度 Slider(4–128)+字符类 Checkbox 组+排除歧义字符 Switch；预览框=XL 只读等宽+右侧 `[重新生成][复制][填入新建]` 横排；"强度计"紧贴预览框下缘（zxcvbn 条，与设置页强度复用同组件）。
- **安全健康**：四卡 2×2 网格（弱/重/久/无TOTP），卡=`[大数字][标题][查看清单链接→]`；列表视图复用条目表+只读过滤器芯片（不可清除负例：进入即已过滤态）。
- **导入导出**：上下两分组（导入在前=冷启动路径）；导入=三步向导（选文件→字段映射/预览 N 条→确认），每步底部按钮对恒右下；导出=单卡：格式/加密选项/目标 PathPicker(L)+ danger 确认词输入（00§3）。
- **历史/设置**：00§6 全套；设置分组序=**锁定策略**（阈值/锁屏/事件）→**剪贴板联动**（清除秒数）→**加密参数**（KDF 只读卡+更换警示）→Hello/防暴力；改主密码表单独立子页：旧密→新密(强度计)→确认新密 三字段纵排，全库重加密进度条在表单下方原位显示（不弹遮罩，可看列表只读）。

> **D-43 实施状态（2026-09-30，C4 落地＋真机实测）**：本节"应然"里**纯前端可达**的那一半已落＝安全参数/条目清单两枚区块各有标题并登记锚点式二级导航（`vault.security`／`vault.entries`，`scope:"anchor"`）、生成器与字段的原生控件清零（`type="number"`→`SpinButton`、裸 `<option>`→`Select`/`Dropdown`）、写死宽度全走 `TIER_W`/`FORM_CARD_W`、清单上 `DataToolbar`＋`ListFooter`（"n / 共 m"），**编辑器由 480px Dialog 改详情抽屉**（本小节的抽屉档位，属行为变更非对等重构：受影响夹具改成显式 `container.querySelector` scoped 查询，不为过测试反向迁就旧 DOM 序）。真机实测（窗口 1280/940 两档）：PanelHeader 48、区块 2 枚齐、锚点判"内容不足一屏（max 0）"；**工具条与页脚在锁定态（未建库）不渲染，解锁态未走查⇒不宣已见**，登记为挂账。未做且继续挂账＝左文件夹树 220px＋虚拟滚动条目表、安全健康四卡 2×2、导入导出三步向导、历史/版本、附件与 TOTP 曲线——均需新 Rust 命令，超 D-43 硬约束。

### 7.2 配套功能缺口（并入 §2/§3 对应行）

1. **与剪切板模块互斥红线**（跨模块，与 01§7.2-⑥ 成对）：库内任何"复制"动作走**直连通道不落历史**（屏蔽 origin 标记）；负例：复制条目口令→`clipboard_search` 无该明文；锁库后历史里也**不得**存在曾从库外粘贴进入的口令回波（依赖 01§7.2-① 屏蔽规则预设）。
2. **轮换备份**（配合件，KeePass 正统）：每次写库后异步滚动备份 `{appData}/vault/backups/`（保留 N 份可配），设置页"从备份恢复"入口（恢复前 diff：库条目数 旧→新）——改主密码/导入这类高危操作的前置保险，也兜住"手滑删了一整个文件夹"。
3. **锁定事件矩阵**（设置子面板 SwitchSetting 组）：空闲 N 分钟（已有）+ 锁屏即锁 + 合盖即锁 + 远程会话断开即锁 + 失焦超时锁（默认关，键盘记录器场景刚需）——§1"阈值无 UI"只是第一层，**触发源可配**才是完整的自动锁配套。
4. **TOTP 时钟偏移校准**：设置内"手机验证码与本机不准？"卡：输入当前 6 位码→后端反解偏移量存储，生成时叠加（RFC6238 容差 ±1 步之外的持久解）——小人群大救急。
5. **条目级"同步排除位"**：与 B5 数据集联动——单条目可标"不参与同步"（家庭库/公司库边界），默认全参与；红线不变：vault 整库永不进 sync（此项为未来若开放"非敏感字段共享"预留，当前仅登记不实施，挂 DeferredBadge）。

### 7.3 锦上添花

- 详情抽屉 URL 行右侧"打开"小钮（浏览器直达）+ 用户名行"自动填充到前台窗口"（AutoType 单字段版）；
- 搜索下拉即时结果（标题/用户名二列匹配，Enter 开抽屉、Ctrl+Enter 复制口令）——工具栏搜索框的第一消费场景；
- 锁屏态大卡：中央解锁框 + 库摘要（条目数/上次解锁时间/健康分），密码管理器"关门感"。
