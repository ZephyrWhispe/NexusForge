# 03 密码库面板详细设计（B1 接线 + 深化）

> 总纲：docs/impl/09 §4(B1)/§7；对标：Vaultwarden（蓝本 §3.3 数据模型）+ Bitwarden/KeePassXC/1Password；状态：未开工。

## 1. 现状问题

- 孤儿命令：`vault_change_master_password`、`vault_folder_rename` 后端有 UI 零入口；`vault_entry_get` 未用（编辑全靠列表缓存）。
- 搜索恒空：`vaultEntries` 的 search 参数前端永远传 null——后端过滤器白做。
- 设置缺位：自动锁定阈值/空闲检测策略无配置入口（只有事件驱动的只读倒计时 Badge）；剪贴板清除延迟不可调；解锁冷却参数不可见。
- 蓝本 §3.3 数据模型的 `Card/Identity/SSHKey` 类型与 `Attachment`：类型下拉有但无专属表单；附件后端无实现（勘查：全链无踪迹）。
- UI：编辑用 480px Dialog 全字段一滚到底；文件夹平铺无层级视觉；条目多时右侧列表无虚拟滚动。

## 2. 子面板信息架构

| 子面板 | 类型 | 内容 |
|--------|------|------|
| 条目 | 清单+编辑 | 左文件夹树（含收藏/全部/TOTP 快捷虚拟节点）+ 右条目表（虚拟滚动、类型图标、搜索框接后端）+ **详情抽屉**（占右半区，非 Dialog）：基本/自定义字段/TOTP/历史 四段 |
| 生成器 | 编辑 | 独立页：密码/passphrase/用户名/TOTP 校验；参数持久化；"填入新建条目"按钮 |
| 安全健康 | 概览 | 弱密码/重复/长期未换/无 TOTP 高危项四卡 + 列表 + 修复跳转 |
| 导入导出 | 设置 | 导入 Bitwarden CSV/JSON、KeePass XML；导出加密信封（明文导出=危险操作输入确认词） |
| 历史 | 历史 | 条目版本快照列表（KeePass history 思想）+ 库级操作审计（创建/改密/导出事件） |
| 设置 | 设置 | 自动锁定阈值（空闲分钟/锁屏触发）、剪贴板清除秒数、Hello 管理、防暴力冷却参数、虚拟键盘保护说明（VirtualLock 已在）|

## 4. 其他软件借鉴

- **KeePass AutoType**（§5-①）；**Bitwarden 收藏置顶+类型筛选芯片**：条目表顶过滤条；**1Password 紧急包**（§5-⑤）；**KeePassXC 数据库安全性页**（KDF 参数只读展示 + "更换 KDF"入口样式）→ 设置子面板加"加密参数"卡（Argon2 内存/迭代展示，改动=全库重加密警示）。

## 5. 拓展设计（常人未思）

1. **AutoType 一键登录**：选中条目按 `Ctrl+Alt+Enter` → 焦点窗口注入 `用户名 Tab 密码 Enter`（win-integration SendInput 已有；序列模板可编辑）。红线：仅显式触发后 5s 窗口内有效、锁库即失效、注入前不清其他剪贴板（负例三连）。
2. **复制倒计时可撤销**：复制密码后状态栏出现 N 秒清除进度 chip，点击"保留"取消清除（场景：还没粘贴完就被清了——所有密码管理器的共同痛点）。
3. **SSH Key 专页**：指纹列表 + 复制公钥/生成 `authorized_keys` 行/与 term 面板"用此密钥连接"联动（跨模块）。
4. **重复/泄露检测**：同密码跨条目重复簇视图；可选联网"已泄露密码"检查（k-anonymity range 查询，默认关+明示上云内容仅 SHA1 前 5 字节——红线：绝不含明文与库内容）。
5. **紧急包打印**：主密码恢复指引 + 加密库文件路径 + 校验指纹生成一页 HTML（break-glass，1Password Emergency Kit 思想）——灾难恢复心智是"简单感"面板最缺的深度。

## 6. 验收点

- 改主密码 e2e：改后旧密码登录必拒（红线负例）+ 中途失败库不破；
- 导入 Bitwarden CSV 含公式注入样本（`=cmd`）被净化（安全负例）；
- 健康检测纯函数单测（弱/重判定的正反例夹具）；
- AutoType 时序窗断言；搜索过滤参数真实下推（前端不再 filter）。
